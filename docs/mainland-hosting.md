# 大陆访问迁移准备

当前状态：代码已提供高德官方 JS API 接入、自托管配置与 EdgeOne Makers 安全代理。腾讯云测试项目已建立；**尚未绑定正式域名、尚未完成高德真实接口和大陆网络实测**。原 Sites 网址仍保留。仓库默认 `provider: 'osm'` 是无凭据的开发预览；国内部署容器启动时才切换为 `amap`，不代表已接入真实账号。

## 我们一起准备的资源

| 顺序 | 你本人需要完成 | 接下来可以协助完成 |
| --- | --- | --- |
| 1 | 注册腾讯云账号并按控制台要求实名 | 选择适合这个静态网站的小规格托管资源；购买前确认地域、费用、续费价 |
| 2 | 注册高德开放平台开发者账号并按要求认证 | 创建应用，申请「Web端（JS API）」Key及安全密钥，设置最终域名白名单与配额 |
| 3 | 确定喜欢且可注册的域名，在自己的账号下持有 | 检查域名用途、解析、HTTPS证书与发布步骤 |
| 4 | 按云平台流程完成大陆接入所需的域名备案 | 准备部署目录、网站信息与访问检查；具体要求以平台审核为准 |
| 5 | 在自己的云账号中开通资源，确认计费 | 上传部署包、配置服务端密钥、绑定域名并验证 |

账号入口：[腾讯云控制台](https://console.cloud.tencent.com/)、[高德开放平台](https://console.amap.com/dev/key/app)。不要把密码、短信验证码、安全密钥或云 API SecretKey 写进聊天或 GitHub。登录、实名和支付由账号本人操作。

建议正式方案：**腾讯云大陆区域轻量服务器 + 自有域名 + HTTPS + 高德官方 JS API**。这是本项目当前提供的完整部署配置，包含地图服务端安全代理。服务器、域名和地图接口可能产生费用，先确认实际套餐、配额和续费信息，再购买。若之后选择 CloudBase 静态托管，还需另配安全代理后端，不能只上传静态文件就认为全部完成。

默认测试域名不适合当作长期生产网址：[CloudBase 默认域名访问限制](https://docs.cloudbase.net/service/alias)。大陆接入备案与域名实际要求请跟随所选云服务控制台；我们不预填虚假的备案号，也不会把注册账号当作开通成功。

## 地图接入

- 使用高德官方 `https://webapi.amap.com/maps?v=2.0`，不抓取无授权的瓦片地址。
- 底图、地点搜索与步行/骑行/驾车算路走高德；公交/地铁仍保留手动换乘说明，不假装是已计算的公交线路。
- 旅程备份、AI导入和照片地点始终保存 WGS84。显示时转换为高德坐标；搜索、选点、拖动与道路结果转回 WGS84，避免重复转换。转换用于旅行点位展示，不能作测绘坐标依据。
- 高德 Key 是公开的浏览器应用标识，应限制域名和配额。安全密钥只放服务端环境变量；`/_AMapService` 为同源代理。[高德官方安全配置](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)
- 高德加载失败时显示明确状态与本地示意图，**不自动转回境外服务**。
- 地图原有标志与版权信息保留，不能用样式隐藏。
- 高德服务的区域覆盖和计费以账号实际开通能力为准；海外旅程可继续使用 OSM 配置。

## 部署文件（已有账号、域名与证书后再执行）

需要服务器安装 Docker 与 Compose。选择服务器和镜像下载来源前确认供应商在该区域的支持方式；当前环境未运行 Docker，容器启动尚待真实主机验证。

1. 运行 `python3 scripts/package_mainland.py` 生成不含密钥的 `work/xingjian-mainland.tar.gz`，上传并解压到服务器项目目录。
2. 复制 `.env.example` 为 `.env`，**在服务器本地**填写高德 Web JS Key 与安全密钥。不要提交此文件。
3. 创建 `deploy/certs/`，放入所用域名的 `server.crt` 与 `server.key`，私钥限制读取权限；证书域名须与访问域名匹配。
4. 将域名 DNS 解析到服务器，在高德控制台设置相同域名白名单；按平台流程完成备案。安全组只按实际部署开放必要端口。
5. 在项目目录运行 `docker compose up -d --build`。配置会提供 HTTPS，并将 HTTP 重定向到 HTTPS。启动时生成国内地图配置，注入服务端安全代理；未配置密钥或证书会停止启动。
6. 使用自己的域名验证：网页、底图、地点搜索、每种已开通交通方式算路、图钉拖动、照片地点、旅程导入导出。
7. 请至少一位朋友用大陆手机流量、一位用宽带直接打开测试，通过后再把新网址作为正式分享地址。本文不把海外节点测试视为大陆可用证明。

密钥轮换：修改服务器 `.env` 后运行 `docker compose up -d --force-recreate`。证书更新后重启容器。安全代理设有请求限速，但仍需在高德控制台设置配额并检查用量。

## 迁移你的行程与照片

换域名后，浏览器不会自动带走旧域名的 localStorage / IndexedDB。迁移前在旧站导出**完整备份（含照片）**，在新站导入；分享链接只包含路线，不包含个人照片。本部署包只携带仓库示例和许可照片，不包含浏览器私人相册。

## EdgeOne Makers 免费托管配置

腾讯云测试项目 `xingjian` 已通过直接上传建立。正式域名尚未购买，系统默认域名仅用于限时预览，不能当作长期分享地址。

无需购买服务器的配置方式：

1. 高德 Web JS Key 白名单限制为项目的实际域名。Key 创建和协议须由账号持有人确认。
2. 在腾讯云该项目的服务端环境变量中填写 `AMAP_JS_KEY` 与 `AMAP_SECURITY_CODE`。安全密钥不要写入静态文件、GitHub、工单或截图；只在已授权的项目中配置。
3. 运行 `python3 scripts/package_edgeone.py`，把生成的 `work/xingjian-edgeone.zip` 上传为同一项目的新部署。包包含站点文件与 `edge-functions`，不含任何密钥。
4. `/api/map-config` 只返回公开的 Web JS Key；`/_AMapService/*` 只代理允许的高德搜索和路径接口，服务端注入安全密钥。未配置、超时和错误时返回明确失败，不回退到境外服务。
5. 配置环境变量后需要新部署生效，再检查高德白名单、点位与算路。正式域名确定后更新白名单、解析和 HTTPS，并按区域要求完成备案。

函数调用有平台额度；高德配额和授权适用范围以账号及当前条款为准。不启用自动付费升级。

官方资料：[直接上传支持函数](https://cloud.tencent.com/document/product/1552/127371)、[Edge Functions 与环境变量](https://cloud.tencent.com/document/product/1552/127416)。
